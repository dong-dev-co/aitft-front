Security

믿고 맡길 수 있는 구조

고비용 실행, 외부 전송, 파일 변경, 최종 확정에는 항상 사람의 확인 절차가 있습니다.

1

경로 봉쇄는 코드에서만

AI 직원은 배정된 작업 폴더를 벗어날 수 없습니다. realpath로 재확인하며, 경로 이탈 시도는 승인 대상이 아니라 즉시 차단됩니다.

2

승인은 OS 기본 대화상자

파일 쓰기·삭제 승인 창은 운영체제 기본 대화상자로 표시됩니다. 모델이 만든 화면으로는 흉내낼 수 없고, 기본 선택은 항상 거부입니다.

3

팀 규칙은 AI에게 읽기 전용

AI 직원은 자신에게 적용되는 팀 규칙 파일을 읽을 수 있지만 고칠 수 없습니다. 자기 지시를 스스로 바꿀 수 없도록 막습니다.

4

API 키·세션은 OS 암호화 저장소

API 키와 로그인 세션은 평문으로 저장되지 않으며, 화면(렌더러)에는 토큰이 전달되지 않습니다.

5

모델 출력은 신뢰하지 않는 입력

AI가 만든 결과물, 문서·MCP의 지시는 참고 정보로만 취급되며 시스템 규칙이나 승인 절차를 우회할 수 없습니다.

Installation

설치 방법

아직 노터라이제이션(Apple 공증)을 거치지 않은 빌드입니다. 처음 실행할 때 한 번 허용 절차가 필요합니다.

.dmg 다운로드

위 다운로드 버튼으로 AI-Company-Tycoon-0.1.0-arm64.dmg를 받습니다. Apple Silicon(M1 이상) Mac을 지원합니다.

Applications 폴더로 이동

dmg를 열고 AI Company Tycoon 아이콘을 Applications 폴더로 드래그합니다.

첫 실행 허용

공증되지 않은 앱이라 macOS가 최초 실행을 막을 수 있습니다. 앱 아이콘을 control 키를 누른 채 클릭하고 열기를 선택하세요.

⚠️ "손상되었기 때문에 열 수 없습니다"가 뜨면 터미널에서 xattr -cr /Applications/AI\ Company\ Tycoon.app 실행 후 다시 여세요.

API 키 연결

연결 설정에서 사용할 모델 제공자(Anthropic, OpenAI, Google)의 API 키를 입력합니다. 키는 OS 암호화 저장소에 보관됩니다.

AI 직원 채용 후 시작

직원 관리에서 역할에 맞는 AI 직원을 채용하고, 업무 보드에서 업무를 만들어 배정하면 바로 시작할 수 있습니다.

FAQ

자주 묻는 질문

로그인해야 쓸 수 있나요?

아니요. 로그인은 선택 사항입니다. 로그인하지 않아도 모든 핵심 기능이 로컬에서 그대로 동작합니다. Google 계정으로 로그인하면 기기 간 동기화가 켜집니다.

로그인하면 동기화를 끌 수 있나요?

로그인 자체는 선택이지만, 일단 로그인한 뒤에는 동기화가 자동으로 켜지며 이를 개별적으로 끄는 옵션은 없습니다. 동기화 없이 로그인만 하고 싶다면 로그아웃 상태(로컬 모드)로 사용하세요.

API 키는 어디에 저장되나요?

운영체제의 암호화 저장소(키체인)에만 저장됩니다. 데이터베이스나 화면 상태에 평문으로 남지 않으며, 기기 간 동기화 대상에도 포함되지 않습니다.

오프라인에서도 사용할 수 있나요?

네. 로컬 우선(local-first) 구조라 오프라인에서도 업무 생성·관리가 가능합니다. 다만 AI 직원의 실제 업무 실행에는 해당 모델 API 호출을 위한 네트워크 연결이 필요합니다.

Windows나 Intel Mac도 지원하나요?

현재 배포되는 빌드는 Apple Silicon(M1 이상) macOS용입니다. Windows·Intel Mac 지원은 로드맵에 있으며 아직 제공되지 않습니다.

실행 취소나 파일 삭제가 안전한가요?

AI 직원의 파일 쓰기·생성은 실행당 1회, 삭제는 매번 OS 기본 승인 대화상자를 거칩니다. 기본 선택은 항상 거부이며, 작업 폴더 밖 경로 접근은 승인 여부와 무관하게 코드 수준에서 차단됩니다.
